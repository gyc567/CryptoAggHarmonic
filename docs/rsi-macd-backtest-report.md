## 三、核心改进分析

### 1. B 档信号质量大幅提升（最重要）

v4 的 B 档 6 个信号全部亏损（0% 胜率）。v5 通过以下改进：

- **Regular/Hidden 背离过滤**：排除了 Hidden 背离的误导信号
- **MACD 零线过滤**：避免 MACD 在零轴同侧（行情可能已走完）的信号
- **双指标共振加成**：只有 RSI + MACD 同时出现 Regular 背离才给 +8 分

结果：B 档信号从 6 → 29（更丰富的候选），胜率从 0% → 58.3%。

### 2. C 档胜率提升（+8.1 pp）

C(参考) 档是最大样本组（125-177个信号），胜率从 78.3% → 86.4%，提升了 8.1 个百分点，相当于每 12 个 C 档信号多赢 1 个。

### 3. 信号更严格（决策数 -28%）

v5 的共振评分更严格（过滤掉 Hidden 背离、不给 MACD 零轴同侧加分），总信号从 183 → 154（-16%），决策数从 47 → 34（-28%）。这意味着 **信号质量提高，但交易频率下降**。

### 4. Profit Factor 提升（2.83 → 3.08，+8.8%）

Profit Factor = 总盈利 R / 总亏损 R。即使胜率持平，Profit Factor 提升说明 **盈亏比改善**——平均盈利幅度增大，平均亏损幅度减小。

## 四、不足与改进方向

### 1. XABCD 样本过小（4-5个信号）

这是本次回测最显著的问题。XABCD 形态是谐波交易的核心，但 900 天回测中只有 4-5 个 XABCD 形态被检测到：
- 原因：pyharmonics 的 HarmonicSearch 在 4H 周期上对 XABCD 的检测非常严格
- 影响：XABCD 组的数据不具统计意义（p > 0.05）
- 解决方向：延长回测周期到 3-5 年，或在 1D 周期上验证

### 2. 总 R 下降（+5.17 → +3.74）

决策数减少 28% 导致总 R 下降。需要在以下方向平衡：
- 适当放宽 `a_grade_min`（从 70 回调到 72-73）
- 重新评估 `hidden_divergence_penalty = -5` 是否过严（可以改为 0 或 -3）

### 3. B 档损失 R 为负（-1.00 / -1.14）

B 档的平均 R 仍然是负的，说明 B 档的止盈/止损设置需要优化。可以考虑：
- B 档使用更紧的 ATR 止损缓冲（`aggressive` 档）
- B 档的 TP1/TP2 比例调整
